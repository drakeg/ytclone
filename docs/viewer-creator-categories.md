# Viewer, creator, and category behavior

Every authenticated account can use VideoShare as a viewer. Creator capabilities are enabled when the user owns or edits at least one channel. Viewer accounts keep viewer-focused navigation and can opt into creation by creating a channel; creator accounts receive creator-studio navigation and upload access.

Categories are site-wide taxonomy. Authenticated creators can create categories; viewer-only accounts cannot create them. This prevents ordinary viewer accounts from changing the shared taxonomy while still allowing creators to add categories needed for uploads.
